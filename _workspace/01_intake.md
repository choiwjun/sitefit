# 사이트핏 접수 기록

## 현재 목표
사이트핏을 다양한 업종의 회사가 홈페이지 검색이해도, AI 검색준비도, 전환 구조를 진단하고 개선 실행으로 연결하는 전체 범위 제품으로 구축합니다. 고객과 운영자에게 노출되는 문구는 한글을 기본으로 합니다.

## 작업 분류
전체 제품 기능 개발.

## 선택한 워크플로
Harness 접수 -> 제품/기술 스펙 -> 디자인 핸드오프 -> 구현 -> 테스트/QA -> 최종 검증

## 제품 정의
사이트핏은 단순 리포트 판매형 SaaS가 아니라 진단을 통해 홈페이지 문제를 드러내고 상담, 견적, 개발/콘텐츠/마케팅 개선 작업, 재진단, 월간 관리로 전환시키는 실행 연결형 인프라입니다.

## 고정 방향
- 사이트 자동 수정 서비스로 표현하지 않습니다.
- 고객-facing 문구에 worker, AI worker, digital worker를 사용하지 않습니다.
- 검색 순위 상승, 트래픽 증가, AI 답변 노출을 보장하지 않습니다.
- AI는 단독 판단자가 아니라 구조화된 근거를 설명하고 작업화하는 보조 역할입니다.
- 핵심 진단은 객관적 근거가 있는 룰 기반으로 수행합니다.
- 공개 첫 진단은 URL만 입력받습니다.
- 무료/유료 구분 없이 전체 진단 결과를 보여줍니다.

## 주요 사용자
- 홈페이지가 있지만 검색 유입, 문의, 구매, 예약, 지원, 제휴 전환이 약한 사업자와 운영자.
- B2B 기업, 제조업, 학원, 쇼핑몰, 프랜차이즈, 병원, 법률사무소, 금융, 부동산, 식음료, 뷰티, 여행, 미디어, 공공/비영리 등.
- 진단 요청, 리드, 상담, 견적, 파트너 배정, 재진단, 월간 관리를 관리하는 내부 운영자.
- 향후 제작사, 마케팅 대행사, SEO 프리랜서, 콘텐츠 에이전시, 개발 파트너.

## 전체 범위
- URL-only 공개 진단 폼.
- 제한 크롤링과 보안 차단.
- 기술 SEO, 검색이해도, AEO, GEO, 전환 구조 진단.
- AI 보조 요약, 대표용 설명, 작업지시서, 견적 범위 분류.
- 전체 진단 결과 공개.
- 예산, 희망 작업, 일정이 포함된 상담 신청.
- 관리자 영업 대시보드.
- 이슈 카드, 리포트, 재진단, 개선 패키지, 월간 관리, 파트너 배정.

## 제외 범위
- 고객 사이트 소스 자동 수정.
- 고객 사이트 자동 배포.
- 검색/AI 노출 성과 보장.
- 제한 없는 크롤링.
- 원본 HTML 전체를 무제한으로 외부 AI에 전달하는 구조.

## 수용 기준
- 제품 스펙과 디자인/구현/QA 산출물이 존재해야 합니다.
- 공개 화면, 관리자 화면, 리포트, API 메시지의 주요 고객 노출 문구가 한글이어야 합니다.
- 공개 진단 폼은 URL만 입력받아야 합니다.
- 진단 결과는 mock 샘플 데이터가 아니라 실제 수집/분석 데이터에 기반해야 합니다.
- 전체 개선 유형과 작업지시서가 모두 공개되어야 합니다.
- 테스트와 수동 검증이 통과해야 합니다.
