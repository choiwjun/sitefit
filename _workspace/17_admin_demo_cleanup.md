# 관리자 데모 데이터 정리 기능

작성일: 2026-05-02

## 목적

영업 데모를 반복 실행하면 데모 run, 리드, 견적 초안이 로컬/운영 저장소에 누적된다. 실고객 데이터와 샘플 데이터를 분리해 볼 수 있는 필터는 이미 추가했지만, 장기적으로는 관리자만 명시적으로 데모 데이터를 정리할 수 있어야 한다.

## 구현 내용

- `DELETE /api/admin/demo-data`
  - 관리자 인증 필요
  - 요청 본문에 `{ "confirm": "DELETE_DEMO_DATA" }`가 있어야 실행
  - 확인 문구가 다르면 400 응답
- `JsonStore.deleteDemoData()`
  - `demoFixtureId`가 있는 진단 run 삭제
  - `demoFixtureId`가 있는 리드 삭제
  - 데모 리드에 연결된 견적 삭제
  - 데모 리드에 연결된 메모 삭제
  - 데모 견적에 연결된 배정 삭제
  - 데모 리드에 연결된 월관리 계정 삭제
  - 파트너 목록과 실고객 데이터는 유지
- `public/admin.html`
  - `데모 데이터 정리` 버튼 추가
  - 브라우저 prompt에 `DELETE_DEMO_DATA`를 입력해야 API 호출
  - 정리 후 삭제 건수 요약 표시
  - 정리 후 `데모만` 필터 유지

## 검증

- `test/server.test.js`
  - 잘못된 확인 문구는 400
  - 데모 run/lead/estimate 삭제
  - 실고객 lead 유지
- `test/admin-ui.test.js`
  - 관리자 UI에 삭제 버튼, API 경로, 확인 문구, 핸들러가 포함되는지 검증

## 주의

이번 작업은 기능을 추가했지만, 현재 로컬 저장소의 데모 데이터는 실제로 삭제하지 않았다. 삭제는 관리자 화면에서 확인 문구를 입력해야만 실행된다.
