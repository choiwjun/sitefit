# 관리자 데모 생성 결과 링크

작성일: 2026-05-02

## 목적

영업 데모 실행 후 생성된 리포트를 바로 열 수 없으면 시연 흐름이 끊긴다. 데모 생성 직후 관리자 화면에서 리포트 링크, 리드 ID, 견적 ID를 즉시 확인할 수 있게 했다.

## 구현 내용

- `public/admin.html`
  - `state.demoRunResult` 추가
  - `renderDemoRunResult()` 추가
  - 데모 생성 성공 시 `리포트 열기` 링크 노출
  - 생성된 리드 ID와 견적 ID 노출
  - 데모 생성 직후 `데모만` 필터로 자동 전환
- `test/admin-ui.test.js`
  - `renderDemoRunResult`
  - `demoRunResult`
  - `demo-report-link`
  - 데모 생성 후 `demo-scope-filter` 자동 전환 코드를 검증

## 효과

관리자는 데모 업종을 선택하고 `데모 리포트 생성`을 누른 뒤 바로 리포트를 열어 영업 시연을 이어갈 수 있다. 동시에 파이프라인은 데모 데이터만 보이도록 자동 전환되어 샘플 데이터가 실고객 리드와 섞여 보이는 문제를 줄인다.

## 다음 권장 작업

관리자 화면에서 실제 브라우저 QA를 수행해 데모 생성 버튼, 필터 자동 전환, 리포트 링크가 시각적으로 자연스럽게 동작하는지 확인하는 단계가 좋다.
