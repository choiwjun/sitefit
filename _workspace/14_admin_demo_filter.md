# 관리자 데모 데이터 필터

작성일: 2026-05-02

## 목적

데모 리포트를 여러 번 생성하면 관리자 파이프라인에 샘플 리드와 견적이 쌓인다. 실고객 리드와 데모 데이터를 구분해서 볼 수 있도록 관리자 화면에 데이터 범위 필터를 추가했다.

## 구현 내용

- `public/admin.html`
  - 상단 필터에 `데이터 범위` 셀렉트를 추가했다.
  - 옵션: `전체`, `실고객만`, `데모만`
  - 리드, 파이프라인, 상담 메모, 견적, 진단 기록, 추천 패키지 요약이 같은 범위 필터를 따른다.
  - `demoFixtureId`가 있는 record를 데모 데이터로 판단한다.
  - 진단 기록 목록에는 데모 run에 `Demo` 배지를 표시한다.
- `public/styles.css`
  - `Demo` 배지 스타일을 추가했다.
- `test/admin-ui.test.js`
  - 데모 범위 필터와 관련 helper가 관리자 화면에 포함되는지 검증한다.

## 주의

이번 작업은 삭제 기능이 아니다. 데모 데이터를 실제로 지우는 기능은 운영 데이터 손실 위험이 있으므로 별도 확인 후 구현하는 편이 맞다.

## 다음 권장 작업

데모 데이터 삭제가 정말 필요하면 `DELETE /api/admin/demo-data`를 별도 관리자 API로 만들고, 삭제 전 확인 문구와 테스트를 붙여야 한다. 그 전에는 현재의 필터 방식이 더 안전하다.
