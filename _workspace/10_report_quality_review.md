# 리포트 문장 품질 리뷰

## 2026-05-02 진행
- 진단 결과가 단순 이슈 목록에서 끝나지 않도록 `salesTalkTrack`을 추가했습니다.
- 상담용 헤드라인은 가장 낮은 점수 영역, 업종 추정값, 전문가 의뢰 필요 항목 수를 근거로 생성합니다.
- 추천 패키지에는 `salesAngle`을 추가해 왜 이 패키지가 검색/문의/상담 전환에 연결되는지 설명합니다.
- 관리자 리드 상세에는 최신 진단과 리드 URL을 매칭해 바로 말할 상담 포인트를 표시합니다.

## 샘플 검토 기준
- B2B 서비스, 병원/의료, 교육, 제조, 커머스 샘플에서 이슈가 1건 이상 탐지되는지 확인했습니다.
- 각 샘플의 이슈가 추천 패키지로 매핑되는지 확인했습니다.
- 공개 리포트와 공유 리포트에서 `상담 포인트`, 추천 패키지 사유, 패키지별 영업 관점이 노출되는지 확인했습니다.

## 남은 개선 후보
- 실제 외부 URL 5개를 대상으로 과탐지/누락을 수동 리뷰해야 합니다.
