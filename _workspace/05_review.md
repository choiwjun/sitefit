# 리뷰 기록

## 2026-05-02 분석엔진 경쟁력 리뷰

### 판단
현재 분석엔진은 URL-only 진단, 한국어 리포트, AEO/GEO/전환 구조, 작업지시서 생성, 영업 파이프라인 연결에서 차별점이 있습니다. 그러나 무료 진단 플랫폼과 비교하면 크롤 기본 범위, 분석률 표시, 접근성/성능 표준 점수, 이슈 카탈로그 수에서 아직 약합니다.

### 주요 리스크
- 기본 크롤 범위가 10페이지라 소규모 사이트에서도 분석 깊이가 얕아 보일 수 있습니다.
- 고객 화면에 분석 페이지 수는 보이지만 발견/제외/링크 점검/렌더링 여부가 충분히 드러나지 않아 신뢰 형성이 약합니다.
- Lighthouse/PageSpeed, 백링크, 키워드, 접근성 진단은 아직 경쟁 도구 수준에 못 미칩니다.
- HTML 분석은 정규식 기반이라 복잡한 마크업에서 오탐/누락 가능성이 있습니다.

### 이번 스프린트 수용 기준
- 기본 크롤 페이지 수를 무료 진단 경쟁 기준에 맞춰 최소 50페이지로 올립니다.
- 진단 결과 JSON에 분석 커버리지 정보를 포함합니다.
- 공개 결과 화면과 공유 리포트에 분석률, 수집 제외 URL, 링크 점검, JS 렌더링 여부를 표시합니다.
- 변경 후 전체 자동 테스트가 통과해야 합니다.

### 이후 과제
- HTML 파서를 도입해 정규식 기반 추출을 줄입니다.
- Lighthouse/PageSpeed 외부 API 연동은 보류합니다. 현재 단계에서는 외부 API 할당량, 지연, 실패 지점보다 SiteFit rule 기반 점수와 작업 범위 설명이 영업 전환에 더 직접적입니다.
- 접근성, hreflang, redirect chain, duplicate content, mixed content 등 이슈 카탈로그를 확장합니다.
- 업종별 실제 사이트 벤치마크 세트를 만들어 탐지율을 측정합니다.
