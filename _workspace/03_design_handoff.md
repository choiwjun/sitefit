# 디자인 핸드오프

## 공개 진단 화면
- 첫 화면은 마케팅 랜딩보다 실제 진단 사용 흐름을 우선합니다.
- 상단에는 사이트핏 브랜드, 관리자 링크, 홈페이지 검색이해도 진단센터 문구를 배치합니다.
- 진단 폼은 사이트 URL 하나만 받습니다.
- 업종과 현재 목표는 초기 진단 폼에서 제거했습니다.
- 보조 문구는 “초기 진단은 URL 기반 실제 수집 데이터로 진행하고, 상담 신청 단계에서 필요한 정보를 보강한다”는 흐름을 설명합니다.
- 결과 영역은 종합 점수, 한글 요약, 분석 페이지 수, AI 제공 방식, 공유 리포트 링크, 예상 작업 범위, 전체 실제 분석 이슈를 표시합니다.
- 무료/유료 구분 없이 전체 진단 결과를 공개합니다.
- 상담 신청 영역은 이름, 회사명, 이메일, 사이트 URL, 예산, 희망 작업, 일정을 받습니다.
- 진단 후 상담 신청 URL 입력란에는 진단 URL을 자동으로 채웁니다.
- 문구는 순위, 트래픽, AI 노출 보장 없이 준비도와 구조 개선 가능성을 중심으로 표현합니다.

## 리포트 화면
- 리포트 제목은 “사이트핏 진단 리포트”입니다.
- 주요 개선 유형은 중복된 페이지별 이슈를 묶어 표시합니다.
- 작업지시서는 진단된 전체 개선 유형을 모두 보여줍니다.
- 영향도, 범위, 신뢰도, 담당자는 한글 레이블로 표시합니다.
- 리포트는 성과 보장 문구 없이 준비도와 작업 범위를 설명합니다.

## 관리자 화면
- 운영자는 리드, 진단 기록, 견적, 파트너 배정, 월간 관리, SI 패키지를 한 화면에서 확인합니다.
- 리드 상태와 견적 상태는 셀렉트로 즉시 변경합니다.
- 내부 enum 값은 유지하되 화면 표시 문구는 한글 레이블을 사용합니다.
- 관리자 인증이 필요한 경우 로그인 화면에서 관리자 토큰을 입력합니다.

## 접근성/상태
- 필수 필드는 HTML `required`를 사용하고 서버에서도 필수값을 재검증합니다.
- 로딩, 실패, 빈 목록 상태를 한글로 표시합니다.
- 관리자 인증 실패 시 로그인 화면으로 이동합니다.
