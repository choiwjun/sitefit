# 2026-05-01 사이트핏 전체 플랫폼 구현 계획

## 목표
사이트핏을 홈페이지 검색이해도 진단과 SI 영업 전환을 연결하는 전체 범위 플랫폼으로 구현합니다. 축소된 MVP가 아니라 전체 제품 방향을 유지하되, 실행 가능한 단위로 계속 확장합니다.

## 원칙
- 고객 사이트를 자동 수정하지 않습니다.
- 순위, 트래픽, AI 답변 노출을 보장하지 않습니다.
- 핵심 탐지는 룰 기반으로 수행하고 AI는 설명과 작업화 보조로 사용합니다.
- 외부 AI 연동 전까지는 chat mock을 사용하되, 진단 결과 본문은 mock 샘플이 아니라 실제 크롤/룰 진단 근거에서 생성합니다.
- 사용자에게 보이는 문구는 한국어를 기본으로 합니다.

## 구현 순서
1. Harness 산출물과 제품 스펙 정리.
2. 공개 진단 화면과 상담 신청 흐름 구현.
3. 제한 크롤러와 URL 보안 정책 구현.
4. 기술 SEO, 검색이해도, AEO, GEO, 전환 구조 진단 구현.
5. 실제 진단 이슈 기반 AI 보조 리포트와 한국어 작업지시서 생성.
6. 리드 점수화, 상담 필수값 검증, 관리자 요약 구현.
7. SI 패키지 추천, 견적 초안, 견적 상태 전이 구현.
8. 파트너 배정, 월간 관리, 운영 메모 구현.
9. 재진단 비교와 공유 리포트 접근 제어 구현.
10. 크롤링 운영 리스크 완화: byte 제한, depth 제한, query 제한, robots disallow.
11. 공개/관리자/리포트/문서 한국어화.
12. 자동 테스트와 로컬 서버 스모크 검증.

## 검증 기준
- `npm test`가 통과해야 합니다.
- `/health`, `/`, `/admin.html`이 로컬 서버에서 정상 응답해야 합니다.
- 진단 결과와 리포트는 한국어로 표시되어야 합니다.
- 상담 신청은 예산을 포함한 필수 정보를 요구해야 합니다.
- 리포트는 공유 토큰 또는 관리자 인증으로 접근해야 합니다.

## 현재 상태
- 자동 테스트 60개 통과.
- 로컬 서버는 3001번 포트에서 정상 응답.
- 외부 AI는 아직 실제 API가 아니라 mock 경계로 동작.
